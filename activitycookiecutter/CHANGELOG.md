# Activity Cookiecutter Changelog

## 0.1.0

Needs ActivityHub 0.10.0 or later.

- First release: a bare-bones two-player ActivityHub game to copy when starting a new one. Two players each move a dot around a shared field with the keyboard, the mouse or a finger, and anyone else in the Activity watches. The bot runs the game and every screen draws it smoothly. The game says who is playing whom in the hub's people lists, offers an Invite button to a player waiting alone, and picks up again by itself after a dropped connection. Every file explains itself in comments, and the README walks through each piece.
